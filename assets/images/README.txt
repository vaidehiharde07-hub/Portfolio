VAIDEHI HARDE // PROFILE PHOTO INSTRUCTIONS
===================================================================

To display your real photograph on the portfolio:
1. Choose a high-quality portrait or headshot.
2. Save or export it in JPG format.
3. Name it:
   profile.jpg
4. Save it into this directory:
   assets/images/profile.jpg

If profile.jpg is not yet added, the website automatically displays
the stylish cybernetic silhouette placeholder (assets/images/profile-placeholder.svg).
As soon as you add profile.jpg, your photo will appear across all pages!
